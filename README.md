# microfisca
Un simulateur pour comprendre le régime micro-fiscal en moins de 5 minutes avec des exemples chiffrés.

Cet outil est pour :
- ceux qui envisagent de créer une micro-entreprise ;
- les conseillers en création d'entreprise ou experts-comptables (qui veulent un support visuel pour expliquer ce régime).  

Il couvre le régime micro-fiscal classique (avec prélèvement à la source).
